<h1 align="center">Plan de pruebas</h1>

<h2 align="center">SoftwareFJ-Core</h2>

<p align="center">Validación y verificación del sistema</p>

**1. Introducción**

El presente documento establece el plan de pruebas para SoftwareFJ-Core, una aplicación desarrollada en Python para la gestión integral de clientes, servicios y reservas de la empresa Software FJ.

Las pruebas permitirán verificar el funcionamiento de las clases, métodos y operaciones implementadas, así como comprobar la correcta aplicación de los principios de programación orientada a objetos y los mecanismos de manejo de excepciones.

Se contemplarán escenarios exitosos y situaciones de error, con el propósito de evaluar la estabilidad y confiabilidad del sistema.

**2. Objetivo general**

Definir los procedimientos y escenarios de prueba necesarios para verificar que SoftwareFJ-Core cumpla con los requisitos funcionales y técnicos establecidos, garantizando el comportamiento esperado de sus operaciones y el manejo adecuado de excepciones.

**3. Objetivos específicos**

- Comprobar el registro y la validación de clientes.

- Verificar la creación y administración de los diferentes tipos de servicios.

- Validar el cálculo de costos de acuerdo con las características de cada servicio.

- Comprobar la creación, confirmación y cancelación de reservas.

- Identificar y controlar los errores que puedan presentarse durante la ejecución.

- Verificar el registro de eventos y excepciones mediante archivos de texto.

- Comprobar que la aplicación continúe funcionando después de gestionar errores controlados.
