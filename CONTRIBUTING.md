**1. Presentación**

Este documento establece las pautas de organización, participación y colaboración para el desarrollo del proyecto SoftwareFJ-Core.

El propósito de esta guía es facilitar el trabajo conjunto, promover una participación equitativa y mantener una organización adecuada durante las diferentes etapas del desarrollo.

**2. Herramientas de trabajo**

| Herramienta | Uso dentro del proyecto |
|---|---|
| **GitHub** | Almacenar el código, gestionar versiones y coordinar el trabajo colaborativo. |
| **Python** | Lenguaje de programación para desarrollar el sistema. |
| **Visual Studio Code** | Editor de código para escribir, ejecutar y depurar el programa. |
| **Git** | Controlar los cambios y facilitar la integración de aportes. |
